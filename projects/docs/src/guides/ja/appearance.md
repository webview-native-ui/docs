# 外観の切り替えを追加する

設定画面に「端末の配色」と「ダークモード」の2つのトグルを追加し、選んだ見た目をアプリ全体に反映します。

[Ionicアプリへの導入](/standard-setup)を終えたアプリが対象です。先にアプリ全体の見た目を変える処理を用意し、その処理を設定画面のトグルから呼び出します。

## 追加する設定

2つのトグルは、配色元と明暗を別々に選ぶためのものです。たとえば、端末の配色を使いながらライト表示にすることも、テーマの既定色のままダーク表示にすることもできます。

| 設定              | オン                                                         | オフ                 |
| ----------------- | ------------------------------------------------------------ | -------------------- |
| Use device colors | 対応するAndroid 12以降では壁紙などに合わせた端末の配色を使う | テーマの既定色を使う |
| Dark mode         | ダーク                                                       | ライト               |

iOS、ブラウザー、端末配色に対応していないAndroidでは、どちらを選んでもテーマの既定色で表示します。

アプリを起動すると「Use device colors」はオンになり、「Dark mode」はその時点のOS設定に合います。起動中はトグルで選んだ明暗が優先されます。設定画面を開き直しても選択は保たれ、アプリの再起動やページの再読み込みで初期値に戻ります。

## 1. ライト・ダークをアプリから切り替えられるようにする

src/global.cssと、導入時に作成したsrc/native-ui.tsを順に変更します。ここでは、設定画面からアプリ全体の明暗と配色を変えられるようにします。

### 明暗を切り替えるスタイルシートを変更する

導入時のsystem.cssは、OSの設定に合わせて明暗を決めます。トグルで明暗を選べるようにするため、class.cssへ切り替えます。class.cssはion-palette-darkクラスの有無で明暗が変わり、このクラスは後で使うsetModeが付け外しします。

src/global.css（AngularでSCSSを使う場合は src/global.scss）を開き、iOS 26とiOS 27の2つのimportを差し替えます。

<!-- prettier-ignore -->
```diff:src/global.css
@@
- @import '@rdlabo/ionic-theme-ios26/styles/system.css' supports(not (overflow-anchor: auto));
- @import '@rdlabo/ionic-theme-ios27/styles/system.css' supports(overflow-anchor: auto);
+ @import '@rdlabo/ionic-theme-ios26/styles/class.css' supports(not (overflow-anchor: auto));
+ @import '@rdlabo/ionic-theme-ios27/styles/class.css' supports(overflow-anchor: auto);
 @import '@rdlabo/ionic-theme-ios27/dist/css/vertical-bars.css' supports(not (overflow-anchor: auto));
 @import '@rdlabo/ionic-theme-md3/styles/theme.css';
```

### 現在の設定値を持つ変数を用意する

続いてsrc/native-ui.tsを変更します。preferencesに2つの設定値を持たせます。deviceColorsは端末配色のオン・オフ、darkはダークモードのオン・オフです。darkの初期値は起動時のOS設定から取得します。

トグルを押したときに同じテーマを操作できるよう、起動時に作ったテーマを参照する変数 appearance も用意します。

<!-- prettier-ignore -->

### 起動時に設定値をテーマへ反映する

enableDynamicColorsへ明暗の初期値を渡し、返り値をappearanceに入れます。これにより、起動後もappearance.setModeで明暗を変更し、appearance.refreshで使う配色を選び直せます。

端末配色がオフのときは、取得した端末配色を使わず、テーマの既定色で表示するようにします。iOSでは、後で定義するsyncIOSSystemBarsも起動時に呼びます。

### 設定画面から呼び出す関数を追加する

同じファイルの末尾に、次の関数を追加します。

- getAppearancePreferencesは、現在の設定値を返します。設定画面を開いたとき、トグルの初期値を表示するために使います。
- setAppearancePreferencesは、変更した設定値を受け取り、テーマへ反映します。一方のトグルを変えたときも、もう一方の値は保ちます。
- syncIOSSystemBarsは、iOSのステータスバーの文字・アイコンをアプリの明暗に合わせます。画面がダークになったとき、時刻や電池表示も読みやすい色に変えるための処理です。

<!-- prettier-ignore -->
```diff:src/native-ui.ts
@@

+ export function getAppearancePreferences(): AppearancePreferences {
+   return { ...preferences };
+ }
+ 
+ export async function setAppearancePreferences(patch: Partial<AppearancePreferences>): Promise<void> {
+   const paletteChanged = patch.deviceColors !== undefined && patch.deviceColors !== preferences.deviceColors;
+   preferences = { ...preferences, ...patch };
+   await startNativeUI();
+   appearance.setMode(preferences.dark ? 'dark' : 'light');

+ }

+ async function syncIOSSystemBars(): Promise<void> {
+   if (Capacitor.getPlatform() !== 'ios') return;
+   await SystemBars.setStyle({
+     style: preferences.dark ? SystemBarsStyle.Dark : SystemBarsStyle.Light,
+   });
+ }
```

## 2. 設定画面に2つのトグルを追加する

既存の設定画面にion-itemを2つ置き、それぞれにion-toggleを入れます。画面を開くときはgetAppearancePreferencesで値を読み、トグルが変わったらsetAppearancePreferencesへ変更した値を渡します。

以下から、使用中のフレームワークの差分を適用してください。

### Angular / Ionic 9

Signal Formsのモデルに現在の設定値を入れます。トグルがモデルを更新すると、effectからsetAppearancePreferencesを呼んでアプリへ反映します。

<!-- prettier-ignore -->
```diff:src/app/appearance.page.ts
@@

+ import { IonItem, IonToggle } from '@ionic/angular';
+ import { getAppearancePreferences, setAppearancePreferences } from '../native-ui';

 @Component({
   selector: 'app-appearance',
+   imports: [FormField, IonItem, IonToggle],
```

### React

checkedに現在値を渡します。onIonChangeのevent.detail.checkedが変更後の値なので、それをsetAppearancePreferencesへ渡します。画面内の状態も同時に更新し、トグルの表示を合わせます。

## 3. トグルを切り替えて見た目を確認する

ブラウザーでは開発サーバーを起動し、ページを再読み込みします。ネイティブアプリではnpm run build、対象OSのnpx cap sync iosまたはnpx cap sync androidを実行し、再ビルド・起動します。

まずDark modeをオン・オフにし、アプリ全体の背景色と文字色がダーク・ライトに切り替わることを確認します。

対応するAndroid 12以降では、Use device colorsもオン・オフにします。オンなら端末の配色、オフならテーマの既定色になります。壁紙を変えてアプリへ戻ると、オンのときは新しい配色が反映されます。

2つのトグルの4通りの組み合わせを試し、配色元を変えても明暗が保たれ、明暗を変えても配色元が保たれることを確認します。設定画面を開き直したときも、選んだ値が表示されることを確認してください。

iOSでは「OSがライト・アプリがダーク」と、その逆の両方で、時刻や電池表示を読めることを確認します。既存の設定保存処理へ接続する場合は、復元時にもSystemBarsを更新し、再起動後の表示を確認してください。

帳票・印刷・PDF出力があるアプリでは、配色や明暗の変更が出力色へ影響しないか確認します。必要に応じて印刷用の配色を設定してください。確認には、実際の設定画面と主要画面を使います。

配色の対応関係は[Dynamic Colorリファレンス](/projects/capacitor-native-ui/docs/dynamic-colors)を参照してください。
