# キャプチャのタイミングの設定

タブ選択のハイライトなど、ネイティブの更新通知時に見た目がまだ安定していない場合は`captureDelayMs`を使います。Capacitor、Cordova、低レベルの`createWebProjection`で共有する任意の登録設定です。既定値は**50ミリ秒**です。有限かつ非負で、ブラウザーのタイマー上限2,147,483,647 ms以下の値を指定します。

接触検出に対応するネイティブホストでは、リクエストを直ちに準備し、指定した待機中にネイティブのジオメトリをサンプリングします。接触時には待機の終了前でもそのリクエストを優先できます。それ以外のホストではWeb側で準備をデバウンスします。矩形が安定していても、視覚的なアニメーションの終了は証明できません。

置き換える画像の準備が終わるまでは、ソースの所有権とレイアウトの有効性に応じて、前回完了した画像を使える場合があります。オーバーレイを開く際は適格な画像かWebフォールバックを使い、アイドル時のデバウンスを待ちません。そのため、待機時間を長くすると以前の見た目を使う期間も長くなる場合があります。

コントロールの選択、再選択、連続更新の挙動を基に待機時間を決めてください。Liquid Glassに共通のアニメーション時間はなく、変化し続けるコンテンツでは安定した画像を保証できません。取得順序、操作時の方針、タイミングイベントは[操作前キャプチャ](../advanced/preinteraction-capture.md)にまとめています。
