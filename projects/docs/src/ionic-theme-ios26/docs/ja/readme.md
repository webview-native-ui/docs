# Ionic Theme iOS26

IonicコンポーネントにiOS 26の外観とLiquid Glassの操作表現を適用します。

[セットアップ](setup.md) · [ブラウザーで試す](https://ionic-theme-ios26.rdlabo.dev/)

セットアップ例はIonic 9向けです。Ionic 8のAngularアプリでは、`provideIonicAngular` を `@ionic/angular/standalone` からインポートします。

![Liquid Glass のタブバー、リスト、コントロールを使う iOS 26 テーマ](https://raw.githubusercontent.com/webview-native-ui/ionic-theme-ios27/ios26-v9.5.0/screenshots/ios26.png)

## インストール

```sh
npm install @rdlabo/ionic-theme-ios26
```

[セットアップ](setup.md) · [設定](configuration.md)

## ドキュメント

- [ion-item-group](https://webview-native-ui.com/projects/ionic-theme-ios26/docs/using-ion-item-group): inset リストに必要な構造。
- [特殊なマークアップとクラス](https://webview-native-ui.com/projects/ionic-theme-ios26/docs/special-markup): 明示的に使う構造とユーティリティ。
- [ESLint](https://webview-native-ui.com/projects/ionic-theme-ios26/docs/eslint): リスト構造の検査。
- [機能](https://webview-native-ui.com/projects/ionic-theme-ios26/docs/features): CSS 変数、Liquid Glass、個別読み込み、ダークモード。
- [Experimental Animation](https://webview-native-ui.com/projects/ionic-theme-ios26/docs/experimental-animation): タブバーと検索の効果。
- [iOS 18](https://webview-native-ui.com/projects/ionic-theme-ios26/docs/ios-18): iOS 26 だけでテーマを読み込む設定。
- [移行](/docs/migration): 任意の設定簡略化とバージョン別の更新手順。
